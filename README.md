## ✨ Features

### 🏘️ Property Discovery
- Fully **responsive design** — mobile, tablet and desktop
- **Property filtering** by location, type, price range and bedrooms with instant results
- **Property comparison** — compare up to 3 properties side-by-side in a modal table
- **Interactive image gallery** with full-screen lightbox
- **Favorites & Recently Viewed** pages
- **Neighborhood guide** with safety ratings for Lekki, Ikoyi and Victoria Island

### 🧠 Smart Tools
- **Smart Matcher** — matches buyers to homes based on budget and lifestyle
- **Mortgage Calculator** — real-time monthly payment calculations
- **Investment ROI Calculator** — annual ROI and 5-year property value projections

### 📅 Booking & Contact
- **Book a Viewing** — property select, date picker, time slots and live booking summary
- Confirmation in **under 2 hours** with direct agent support
- **Contact form validation** with inline error messages
- **Google Maps** embed on the contact page
- **WhatsApp** direct-chat integration

### 💎 UX & Polish
- **Animated counters** on scroll (Intersection Observer)
- **Testimonial slider** with dot indicators
- **Mobile hamburger navigation** with smooth slide animation
- **Back-to-top button**
- **Newsletter signup** with toast notification
- **Real social links** connected to Adegbite Abdullahi's profiles

## 🌐 Deployment

### Netlify (Recommended)
1. Go to [netlify.com](https://netlify.com) and sign up
2. Drag and drop the project folder into the deploy area
3. Your site will be live instantly with a free `.netlify.app` domain

### GitHub Pages
1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Select "Deploy from a branch" and choose `main`
4. Your site will be available at `https://yourusername.github.io/bulex-homes`
